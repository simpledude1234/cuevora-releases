# Cuevora

Cuevora is a DJ app for Windows with an Auto DJ: it mixes your own music the way a DJ would.

This page holds the installers only. There is no source code here.

## Download

1. Open the **[latest release](../../releases/latest)** and download `Cuevora-Setup-<version>.exe`. (The other two files are for automatic updates; you don't need them.)
2. Double-click it to install.
3. Cuevora isn't code-signed yet, so Windows may warn you. Click **More info**, then **Run anyway**.
   On some newer PCs, Smart App Control blocks unsigned apps completely; Cuevora can't be installed there until it's signed.

From version 0.1.2, Cuevora updates itself: it checks this page for new versions, including security fixes, downloads them in the background, and installs them when you close it. It asks before restarting, so it never stops your music on its own.
